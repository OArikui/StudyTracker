# Windows メディア操作

## 有効化

StudyTracker の「設定」→「Windowsメディア操作」で有効化します。初期状態では無効です。
有効化すると学習画面に小さなメディア操作欄が表示され、再生/一時停止、前/次、音量を操作できます。

## グローバルショートカット

| 操作 | ショートカット |
| --- | --- |
| 再生 / 一時停止 | Ctrl+Alt+Space |
| 前のメディア | Ctrl+Alt+Left |
| 次のメディア | Ctrl+Alt+Right |

ショートカットは Windows のグローバルホットキーとして登録されます。ほかのアプリが同じ組み合わせを先に登録している場合、その組み合わせは登録できません。アプリ終了時に登録を解除します。

音量ボタンは Windows の標準音量キーを使います。再生操作は Windows のアクティブなメディアセッションに送られます。

## メディア情報と優先セッション

Windows の GSMTC API からアプリID、タイトル、アーティスト、アルバム、再生状態を取得します。複数セッションがある場合はドロップダウンから優先セッションを選びます。学習中は情報が変化したときだけ media_state イベントを既存の events テーブルに保存します。DBスキーマの変更はありません。

GSMTC メタデータ取得には Windows Runtime Python projection が必要です。インストールする場合:

```powershell
python -m pip install winrt-runtime winrt-Windows.Media.Control
```

この依存関係がない場合も標準メディアキー操作は使えますが、メディア情報の列挙・優先選択・記録は利用できません。
