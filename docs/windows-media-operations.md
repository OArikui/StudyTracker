# Windows メディア操作

## 有効化

StudyTracker の「設定」→「Windowsメディア操作」で有効化します。初期状態では無効です。
有効化すると学習画面に小さなメディア操作欄が表示され、再生/一時停止、前/次、音量を操作できます。

## グローバルショートカット

| 操作 | ショートカット |
| --- | --- |
| 再生 / 一時停止 | Ctrl+Alt+Space |
| 前のメディア | Ctrl+Alt+Left |
| 次のメディア | Ctrl+Alt+Right |

ショートカットは Windows のグローバルホットキーとして登録されます。ほかのアプリが同じ組み合わせを先に登録している場合、その組み合わせは登録できません。アプリ終了時に登録を解除します。

音量ボタンは Windows の標準音量キーを使います。再生操作は Windows のアクティブなメディアセッションに送られます。

## メディア情報と優先セッション

Windows の GSMTC API からアプリID、タイトル、アーティスト、アルバム、再生状態を取得します。複数セッションがある場合はドロップダウンから優先セッションを選びます。学習中は情報が変化したときだけ media_state イベントを既存の events テーブルに保存します。DBスキーマの変更はありません。

GSMTC メタデータ取得には Windows Runtime Python projection が必要です。インストールする場合:

```powershell
python -m pip install winrt-runtime winrt-Windows.Media.Control
```

この依存関係がない場合も標準メディアキー操作は使えますが、メディア情報の列挙・優先選択・記録は利用できません。

## メディア情報が取得できない場合

メディア操作とメディア情報の取得は別の機能です。標準の Windows メディアキーは操作に利用できますが、タイトル・アーティスト・再生位置などの取得には GSMTC と Python/WinRT の任意依存関係が必要です。

1. StudyTracker を起動している Python 環境で、リポジトリのルートから次を実行します。

   ```powershell
   python -m pip install -e ".[windows-media]"
   ```

   リポジトリをインストールせずに使う場合は、次でも導入できます。

   ```powershell
   python -m pip install winrt-runtime winrt-Windows.Media.Control
   ```

2. StudyTracker を完全に終了し、再起動します。
3. 「設定」→「Windowsメディア操作」を有効にします。
4. 対応するブラウザやプレーヤーでメディアを再生し、Windows のメディアフライアウトにセッションが出るか確認します。
5. 複数のセッションがある場合は、学習画面の「メディア優先対象」から操作対象を選択します。

### よくある原因

- **セッションは検出されるが、再生位置が取得できない**: タイムライン情報を公開しないプレーヤーでも、タイトルやアーティストは独立して表示される設計です。ステータスに「情報の一部を取得できません」と出る場合は、`user_data/logs` 内の最新ログで `study_tracker.media` の詳細を確認してください。
- **セッション数が表示されるのにタイトルが空**: プレーヤーがメディア詳細をまだ公開していない可能性があります。再生を開始して少し待ち、ログに表示される取得エラーを確認してください。

- **winrt が必要という表示**: 任意依存関係が未導入です。StudyTracker を実行しているものと同じ `python.exe` でインストールしてください。
- **セッションが空**: プレーヤーが Windows GSMTC に情報を公開していない、または現在メディアを再生していない可能性があります。
- **再生操作はできるが情報が出ない**: 標準メディアキーは GSMTC メタデータ取得を必要としないため、これは起こり得ます。
- **再生位置バーが無効**: プレーヤーが再生時間やシーク API を公開していない場合、位置変更は利用できません。

アプリの「設定」→「メディア取得の案内」からも、この手順を確認できます。
