# 定期バックアップの使い方

メニューの「設定」→「定期バックアップ」で、自動バックアップを設定します。

- 有効化: 定期バックアップをオン／オフにします。
- 実行間隔: 6時間、12時間、毎日、毎週から選択できます。初期値は毎日です。
- 保存先: 初期値は SQLite データベースの隣にある `backups` フォルダーです。別のドライブも指定できます。
- 保持世代数: 初期値は14です。新しいバックアップが正常に作成された後、古い世代を整理します。

バックアップは SQLite のバックアップ API で作成するため、StudyTracker の実行中でも保存できます。履歴がない場合は起動後に初回バックアップを作成します。失敗時はエラーを表示し、15分後以降に再試行します。

「今すぐバックアップ」は、入力中の保存先と保持世代数で直ちにバックアップを作成します。設定は Save を押すまで保存されません。

ファイル名は `study_tracker_backup_YYYYMMDD_HHMMSS_microseconds.sqlite3` 形式です。復元時は StudyTracker を終了し、現在の DB を別名で退避してからバックアップファイルを復元してください。
