# StudyTracker ViewerV0

Version: **0.8.1**

StudyTracker 本体と共有する SQLite データベースを読み取り・可視化するデスクトップビューアーです。記録、タイムスタンプ、実施範囲を編集できます。

## v0.8.1 の変更点

- StudyTracker 本体から渡された `database_path` を起動時に受け取るよう修正。
- Viewer 独自の DB 選択 UI と `%APPDATA%/ViewerV0/config.json` による DB 設定を廃止。
- DB パス変更は StudyTracker 本体の「使用ディレクトリ・ViewerPack設定」でのみ行う構成に統一。

## v0.8.0 の変更点

- テーブルタブのタイムラインを「縦軸＝日付、横軸＝00:00〜24:00の時刻」に変更。日付ごとの行で比較できます。
- タイムライン操作をマウスホイールに集約。ホイールで拡大・縮小、Shift+ホイールで時刻方向に移動、ドラッグで範囲拡大、ボタンで24時間表示に戻れます。
- タイムラインの拡大率・表示位置スライダーを廃止。タイムライン上のタイムスタンプをクリックすると編集できます。
- タイムスタンプの時刻、位置、単位、科目、教材を編集可能にしました。
- 学習記録の開始・終了日時、Active/Passive、科目、教材、位置、単位、予定範囲、実施範囲、備考を編集可能にしました。
- 記録・タイムスタンプ・実施範囲の編集は、変更前／変更後を `viewer_edit_history` テーブルへ追記します。UIに履歴閲覧画面を追加しました。通常の画面操作では履歴を編集・削除できません。ただし、SQLite ファイル自体に書き込みできる人による直接改変まで暗号学的に防止するものではありません。
- 学習記録テーブルを Active/Passive で色分けし、右端に区間時間の棒グラフを追加。
- 日別勉強時間と時間当たりの勉強量の各推移グラフに、科目選択と折れ線／棒グラフの切替を追加。
- グラフの縦幅と軸の余白を増やし、単位「学習単位/時」を表示。
- ヘッダーとフッターにバージョン情報を表示し、タブ履歴を戻る／進むボタンで移動可能にしました。
- フィルター項目のラベルと入力欄を隣接させ、期間に「今日」「今週」「カスタム」を追加。開始日・終了日を表示し、プリセット選択と連動します。
- 起動コード、テスト、パッケージのディレクトリ名を `viewer_v0` に統一しました。

## 起動

Python 3.10 以降と `requirements.txt` の依存パッケージが必要です。

ViewerPack は StudyTracker 本体から起動してください。本体は設定済みの `db_path` を `database_path` として渡します。ViewerPack 単体では別の DB を選択できません。

## データベースと編集履歴

- StudyTracker 本体が渡した `db_path` を開き、`segments` と `timestamps` を読み込みます。
- 実施範囲は StudyTracker 本体と共有する `segments.row_json` に保存します。
- 記録の編集では `segments.start_at`、`segments.end_at`、`segments.active` と `segments.row_json` を更新します。開始日時を変更した場合は関連タイムスタンプの `segment_start_at` も更新します。
- タイムスタンプ編集では `timestamps` の時刻・位置・単位・科目・教材を更新します。
- 変更履歴は同じ DB 内の `viewer_edit_history` に追記します。履歴には変更日時、対象、対象 ID、変更前 JSON、変更後 JSON が入ります。
- DB書き込み時に SQLite の `busy_timeout` を設定します。StudyTracker 本体と同時利用中にロックされた場合は、メッセージを確認して再試行してください。

## 主な機能

- 期間、学習区分、科目、教材、キーワード、Active/Passive で絞り込み
- 総勉強時間、学習日数、セッション数、区間数、平均区間、最長区間を表示
- 日別・科目別・教材別の勉強時間グラフ、および時間当たりの勉強量推移
- 学習予定範囲と実施範囲の分離表示
- 記録・タイムスタンプ・実施範囲の編集および変更履歴の閲覧
- 表示中の記録を CSV 出力

## ディレクトリ構成

- `main.py`: 起動スクリプト
- `viewer_v0/`: アプリ本体
- `tests/`: SQLite リーダー・ライターのテスト
